## Decisiones tomadas en Discovery

- **D-U1:** Sistema de componentes = **shadcn/ui + Tailwind** (alineado con PRD A.2)
- **D-U2:** Estilo visual = **Minimalista moderno tipo Linear** (no "cálido local antioqueño")
- **D-U3:** Color de acento = **Naranja cálido #F97316** (Tailwind orange-500, evoca comida sin caer en rojo de Rappi)
- **D-U4:** Modo de color = **Solo claro en MVP** (dark mode Fase 2)
- **D-U5:** Modo de trabajo = **Fast Path**
- **D-U6:** Mostrador device = **Tablet detrás de caja** (9-11 pulgadas)
- **D-U7:** Cocina device = **Tablet montada en cocina** (con respaldo a TV/celular)
- **D-U8:** Tipografía = **Geist Sans** (shadcn default, sin overrides de body)
- **D-U9:** Navegación Cliente = **Bottom tab bar** (3 tabs: Home, Mis Pedidos, Cuenta)
- **D-U10:** Navegación Mostrador = **Sidebar persistente** (4 items)
- **D-U11:** Cocina y Domiciliario = **Sin navegación** (una sola vista por surface)
- **D-U12:** Asimetría de confirmación = **Confirmar Pago 1 tap / Rechazar Pago 2 taps** (happy path rápido, friction path con motivo)
- **D-U13:** Optimistic UI = **No para pagos, sí para acciones operativas**
